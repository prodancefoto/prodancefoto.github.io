## GitHub 部署
1. 先备份现有仓库。
2. 解压本压缩包，将其中全部文件和文件夹上传到原仓库根目录，覆盖同名文件。
3. 保留原仓库的部署工作流或平台配置文件。
4. 提交后等待静态站点重新构建。
5. 上线后检查首页、手机端菜单、作品集横向滑动、品牌故事、赵老师简介及电话链接。
